## 🎨 Designer Notes for Fayaz
- **Deck/catalog type:** reference catalog — clean, gridded, scannable. This is the "spec sheet" people flip to.
- **Feature cards:** render each row as a **card** (icon + feature name + one-line benefit) grouped under its category header — or keep as clean tables if space is tight.
- **Category icons:** one distinct icon per category (Job Posting, Candidate Search, Branding, Screening, Communication, Analytics, Compliance/Team; and for seekers Onboarding, Profile, Discovery, Apply, Engagement, Language).
- **Live vs roadmap legend:** a small, consistent badge system — e.g. **● Live** (solid) vs **○ Roadmap** (outline). Put the legend on every page.
- **Two clear halves:** Employer section and Job Seeker section visually distinct (different accent colour per side), Platform section as a neutral footer band.
